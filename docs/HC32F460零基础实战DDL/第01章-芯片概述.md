# 第 1 章 HC32F460 芯片概述

写代码之前，先认识你要操作的这块芯片。这一章的内容大部分不针对 DDL，而是关于 HC32F460 这颗芯片本身：它的内核、存储器怎么编址、片内集成了哪些外设。这些信息在芯片数据手册里都有，但手册有上千页，这里挑出对编程真正有影响的部分。

---

## 1.1 芯片定位

HC32F460 是小华半导体（HDSC）基于 ARM Cortex-M4F 内核的通用 MCU，主频最高 200MHz。它的对标产品是 ST 的 STM32F4 系列，两者定位接近，外设配置也大致相当。

你的开发板上焊的型号是 **HC32F460JEUA**，LQFP100 封装。型号里每个字符都有含义：

```
HC32 F4 60 J E U A
 │    │  │  │ │ │ │
 │    │  │  │ │ │ └── 温度范围/版本
 │    │  │  │ │ └──── 封装（U = LQFP100）
 │    │  │  │ └────── Flash 容量（E = 512KB，C = 256KB）
 │    │  │  └──────── 引脚数/系列细分
 │    │  └─────────── 产品系列 460
 │    └────────────── Cortex-M4 系列
 └─────────────────── 小华 32 位 MCU
```

判断 Flash 容量时看倒数第三个字符：`xE` 是 512KB，`xC` 是 256KB。这个字符决定了你用哪个链接脚本，也决定了程序能有多大。

---

## 1.2 内核

Cortex-M4F 的 "F" 表示带**浮点运算单元（FPU）**，支持单精度浮点指令。这意味着你可以直接用 `float` 做运算而不用软件模拟，做电机控制、信号处理、传感器标定时会快很多。

几个和编程相关的内核特性：

**嵌套向量中断控制器（NVIC）**。管理所有中断的优先级和响应。Cortex-M4 支持最多 240 个外部中断，优先级用 4 位表示（16 级）。HC32F460 在此之上又加了自己的中断控制器，这个话题在第 5 章展开。

**SysTick 定时器**。内核自带的一个 24 位递减计数器，通常用作系统时基。RTOS 的心跳就靠它，第 4 章和第 15 章都会提到。

**存储器保护单元（MPU）**。可选，用于给不同内存区域设置访问权限，裸机开发一般不用，RTOS 里做任务隔离时会用到。

**调试接口**。支持 JTAG 和 SWD。这里有个需要注意的点：部分调试引脚（TDI、TDO/SWO）和 GPIO 复用，如果你要用这些引脚做普通 IO 或驱动外设，必须先禁用调试功能，否则引脚电平不受 GPIO 控制。这一点在你的 LCD 项目里会实际遇到。

## 1.3 存储器映射

这是本章最实用的部分。程序出问题的时候，一半以上和内存布局有关——栈溢出、数组越界、Flash 写错地址，都需要对着地址空间来判断。

从链接脚本 `mcu/EWARM/config/HC32F460xE.icf` 里可以直接读出芯片的地址布局：

### Flash（512KB）

```
0x00000000 ─ 0x0007FFFF    主 Flash，512KB
0x03000C00 ─ 0x03000FFB    信息区（约 1KB）
```

主 Flash 从 0 地址开始，这是 Cortex-M 的规定：复位时内核从 0x00000000 读栈顶，从 0x00000004 读复位向量。你的程序、常量、中断向量表都存在这里。

0x03000C00 那一段是芯片的信息区，存放一些出厂配置。HC32 有一个叫 **ICG** 的机制（上电配置字节），它就放在 Flash 的特定位置，芯片上电时硬件自动读取，用来在看门狗、复位引脚、掉电检测等配置生效前就确定芯片行为。这部分在第 12 章会提到。

### SRAM（192KB，分成 5 块）

这是 HC32F460 比较特别的地方——SRAM 不是连续的一整块，而是分成几个独立的区域，各有用途：

```
起始地址      结束地址       大小    通常名称      说明
0x1FFF8000 ─ 0x1FFFFFFF    32KB   SRAMH        高速 SRAM，与内核同频
0x20000000 ─ 0x2000FFFF    64KB   SRAM1        主 SRAM
0x20010000 ─ 0x2001FFFF    64KB   SRAM2        主 SRAM
0x20020000 ─ 0x20026FFF    28KB   SRAM3        主 SRAM
0x200F0000 ─ 0x200F0FFF     4KB   SRAM_Ret     保持 SRAM，低功耗下可保持
                          192KB   合计
```

**为什么要知道这个？**

第一，**高速 SRAM（SRAMH）的用途**。它挂在和 CPU 同频的总线上，访问没有等待周期。如果你有一段对时间极其敏感的代码（比如高频中断处理、实时控制循环），可以把它放到 SRAMH 里执行。第 4 章讲升频时会看到，SRAM 的等待周期配置是升频必须处理的三件事之一。

第二，**SRAM_Ret 的用途**。它是"保持 SRAM"，在低功耗模式下可以通过备用电源保持数据不丢失。如果你做电池供电的设备，需要在休眠时保存少量状态，就用这块。

第三，**栈和堆的边界**。链接脚本把栈（CSTACK）和堆放在 RAM 的末尾。默认的栈大小只有 0x400（1KB），如果你的函数里有大数组或者用了 `printf` 的浮点格式化（`%f` 很吃栈），很容易栈溢出。栈溢出不会报错，只会让程序行为诡异，是非常难查的一类 bug。

第四，**DMA 的地址约束**。DMA 传输要求源地址和目标地址都在可访问范围内。跨区域传输一般没问题，但如果你发现 DMA 搬运的数据不对，检查一下地址是否落在有效的 SRAM 区间。

### 外设寄存器空间

外设寄存器统一编址在 0x40000000 以上的区域。打开 `mcu/common/hc32f460.h`，你会看到大量这样的定义：

```c
#define bM4_DMA1_DTCTL0_BLKSIZE0  (*((volatile unsigned int*)(0x42A60900UL)))
```

这说明 DMA1 的寄存器组基地址在 0x42A60000 附近。每个外设都有一段连续的地址空间，DDL 驱动里的 `M4_XXX` 指针（比如 `M4_USART2`、`M4_SPI3`）指向的就是各自寄存器组的基地址。

理解这一点有助于读驱动代码：当你看到 `M4_USART2->DR` 这样的写法，就知道它是在直接访问串口的数据寄存器。

## 1.4 片内外设清单

HC32F460 的外设相当丰富。下面按功能分类列出，标注的是 F460 全系列的能力，具体到你的型号可能略有裁剪。

### 通信接口

| 外设 | 数量 | 说明 |
|---|---|---|
| USART | 4 | 支持 UART 异步、时钟同步、智能卡、IrDA、LIN |
| SPI | 4 | 支持 3 线/4 线，主从模式，最高速率达 PCLK/2 |
| I2C | 3 | 支持标准/快速/快速+ 模式，主从可切换 |
| CAN | 1 | 符合 CAN 2.0B，用于汽车和工业现场总线 |
| USB | 1 | USB 2.0 全速 Device/Host |
| QSPI | 1 | 四线 SPI，用于连接外部 Flash，支持内存映射执行 |
| I2S | 1 | 音频数据传输 |
| SDIOC | 1 | SD/MMC 卡接口 |

USART 和 SPI 各有 4 个，编号从 1 开始（USART1~4、SPI1~4）。注意 DDL 里的实例名是 `M4_USART1` 到 `M4_USART4`，而引脚复用功能名是 `Func_Usart2_Rx` 这样的形式，两者编号要对上。

### 定时器

| 外设 | 数量 | 用途 |
|---|---|---|
| Timer0 | 2 单元 × 2 通道 | 基础定时，同步/异步时钟，常用于周期性中断 |
| TimerA | 6 单元 | 通用定时器，PWM 输出、输入捕获、正交解码 |
| Timer4 | 3 单元 | 电机控制专用，带死区互补 PWM |
| Timer6 | 2 单元 | 高级定时器，高精度 PWM |
| RTC | 1 | 实时时钟，日历、闹钟，可由 32.768kHz 驱动 |
| WDT / SWDT | 各 1 | 独立看门狗 / 特殊看门狗 |

Timer0 的每个单元有 A、B 两个通道，这是 HC32 的一个特色：两个通道可以配置不同的时钟源和周期，互不干扰。你的开发板例程 `3.timer0/BaseTimer` 就演示了通道 A 用外部 32.768kHz、通道 B 用内部 PCLK1 同时工作。

### 模拟外设

| 外设 | 数量 | 说明 |
|---|---|---|
| ADC | 2 × 16 通道 | 12 位逐次逼近型，最高 2.5MSPS |
| DAC | 2 | 12 位数模转换 |
| CMP | 3 | 模拟比较器 |
| OTS | 1 | 片内温度传感器 |

ADC 是 12 位，这意味着转换结果范围是 0~4095。参考电压可以选内部基准或外部引脚，通常用 3.3V 电源电压作参考。精度、采样时间、参考电压的选择在第 11 章细讲。

### 数据搬运与安全

| 外设 | 数量 | 说明 |
|---|---|---|
| DMA | 2 单元 × 8 通道 | 支持外设触发和软件触发，块传输 |
| AES / HASH / TRNG | 各 1 | 对称加密、哈希、真随机数 |
| CRC | 1 | 循环冗余校验 |

DMA 有 2 个单元（DMA1、DMA2），每个 8 个通道。你的 LCD 驱动用的是 DMA1 的通道 0 和 1。

### 其他

| 外设 | 说明 |
|---|---|
| GPIO | 最多 83 个 IO，支持外部中断、复用功能重映射 |
| EFM | 内部 Flash 控制器，支持擦写和读保护 |
| PWC | 电源控制，管理时钟门控和低功耗模式 |
| CLK | 时钟控制器 |
| RMU | 复位管理，可查询复位来源 |
| DCU | 数据运算单元，做简单的加减乘除和比较 |
| KEYSCAN | 硬件矩阵键盘扫描 |
| EMB | 紧急制动，电机控制保护用 |
| Event Port | 事件端口，外设间直接联动，不经过 CPU |

## 1.5 和 STM32F4 的对应关系

如果你熟悉 STM32，这张表能帮你快速迁移概念。但要注意，相似不等于相同，配置细节差异很大。

| 功能 | STM32F4 | HC32F460 |
|---|---|---|
| 内核 | Cortex-M4F @ 168MHz | Cortex-M4F @ 200MHz |
| Flash | 512KB / 1MB | 256KB / 512KB |
| SRAM | 128KB + 64KB CCM | 192KB（分 5 区） |
| 系统时钟配置 | `SystemClock_Config()` | `CLK_SysClkConfig()` + PLL |
| 外设时钟使能 | `RCC_AHB1PeriphClockCmd()` | `PWC_FcgXPeriphClockCmd()` |
| GPIO 初始化 | `GPIO_Init()` | `PORT_Init()` |
| 引脚复用 | `GPIO_PinAFConfig()` | `PORT_SetFunc()` |
| 串口 | `USART_Init()` | `USART_UART_Init()` + `USART_SetBaudrate()` |
| 中断服务函数 | 固定名称 `USART1_IRQHandler` | 注册回调 `enIrqRegistration()` |
| Flash 等待周期 | `FLASH_SetLatency()` | `EFM_SetLatency()` |
| DMA | DMA1/DMA2 + Stream | DMA1/DMA2 + Channel |
| 图形化配置工具 | STM32CubeMX | 无官方工具 |

最需要留意的两处差异：

**中断机制不同**。STM32 里中断服务函数的名字是固定的，你写 `void USART1_IRQHandler(void)` 编译器就能接上。HC32 里没有固定名字，你必须调用 `enIrqRegistration()` 把自己写的回调函数挂到某个中断向量上。这个差异会让刚从 STM32 转过来的人很不适应，第 5 章专门讲。

**没有图形化配置工具**。STM32 有 CubeMX 帮你生成时钟树和引脚配置代码。HC32 没有，所有配置都得自己写代码。这正是本书存在的理由，也是学习曲线陡峭的主要原因。

## 1.6 这份资料里没有的东西

有几个芯片特性，在 DDL 包和开发板例程里都没有充分体现，但它们确实存在，遇到问题时值得知道：

**ICG（上电配置字节）**。芯片上电时，在看门狗、复位引脚功能、掉电检测等配置生效之前，硬件会先从 Flash 的固定位置读取一组配置。如果你的程序一上电就复位，而代码看起来没问题，可能是 ICG 配置导致的。原厂例程里有 `icg` 目录可以参考。

**电源模式**。HC32 有多个电源域，高频运行需要切换到高性能模式（`PWC_HS2HP()`）。这个在第 4 章会作为升频的必要条件出现。

**复位来源查询**。芯片复位后可以通过 RMU 模块查询上次是什么导致的复位（上电、看门狗、外部引脚、软件）。做可靠性设计时这个功能很有用，第 12 章会提到。

---

## 1.7 小结

这一章建立了对芯片的整体认识：Cortex-M4F 内核、512KB Flash 从 0 地址开始、192KB SRAM 分成五个区域各有用途、丰富的片内外设。这些信息在后面每一章都会用到。

最需要记住的三个数字：Flash 基址 0x00000000，SRAM 主区从 0x20000000 开始，主频最高 200MHz。
