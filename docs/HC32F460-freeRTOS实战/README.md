# 第二篇 · FreeRTOS 实战:从点灯到图形化万年历

本篇是《HC32F460 零基础实战》的 **第二篇**,承接 **第一篇(DDL)**,参考 [野火《FreeRTOS 内核实现与应用开发实战》](https://doc.embedfire.com/rtos/freertos/zh/latest/index.html) 的框架组织:先系统讲原理,再回到工程逐功能开发。

## 本篇定位

- **不重复 DDL 外设教学**。GPIO、USART、定时器、ADC、SPI 等外设的寄存器与库函数用法请回第一篇;本篇只在"和 RTOS 相关"时点到为止(第 20 章专门做了一轮"只为 RTOS 的 DDL 速览")。
- **原理先行,再落工程**。上半部(原理篇)把任务、调度、通信、中断的"为什么"讲透;下半部(应用篇)回到真实工程,每一章对应一个功能,讲清用到的 API、怎么用、为什么这么用。
- **以真实工程为锚**。所有代码示例来自仓库里的两个工程:
  - 起点:`HC32F460 Demo\example\HC32F460JEUA\1.gpio\gpio_output\`(官方裸机点灯例程)
  - 终点:`project/`(支持串口配置的图形化万年历,FreeRTOS + GUIslice)
- **砍掉用不到的**。野火那套里的"从 0 手写内核"、列表/列表项内部实现、事件标志组、任务通知、低功耗 Tickless、5 种 heap 算法等,本工程用不到,一律只做一句带过。(软件定时器本工程**实际在用**——开机闪屏 5 秒倒计时,故单列一章;墙上时钟的"走时"归硬件 RTC,与软件定时器无关。)
- **一条贯穿全书的架构原则**:**界面只负责展示数据,不参与业务计算**。典型落地是把"墙上时钟"从 `gui.c` 里抽出来,做成独立的"时间服务"(第 26 章)。
