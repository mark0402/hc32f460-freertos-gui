## 9.1 为什么启动页不用 GUIslice

第 38 章提过：启动页代码跑在 `gslc_Init` 之后的"建页面之前"，而且它只需要"一张图 + 一行中文 + 右上角数字"。这种纯展示、无交互的静态画面，用底层 `tftlcd` 直画最直接，不必引入 GUIslice 元素。

所以启动页是"裸机"界面：没有元素、没有页面、没有重绘调度，就是一段顺序执行、靠 `vTaskDelay` 控制节奏的绘制代码。

## 9.2 完整代码逐行

```407:437:project/source/guislice/gui.c
    // --- 立刻画闪屏(立即可见) ---
    uint16_t lx = (LCD_Width  > TITANS_LOGO_W) ? (uint16_t)((LCD_Width  - TITANS_LOGO_W) / 2) : 0u;
    uint16_t ly = (LCD_Height > TITANS_LOGO_H) ? (uint16_t)((LCD_Height - TITANS_LOGO_H) / 2) : 0u;
    LCD_Show_Image(lx, ly, TITANS_LOGO_W, TITANS_LOGO_H, g_au8TitansLogo);
    LCD_ShowChineseStr(lx, (uint16_t)(ly + TITANS_LOGO_H + 6), GREEN, CNSTR_EMS_TITLE);
    log_debug("boot: splash shown");

    // 闪屏倒计时用 FreeRTOS 软件定时器(GUI 私有)自计时、自显示, 与 RTC 无关。
    // 时间加载(读 Flash / 配 RTC)在独立的 "TimeInit" 线程里并发完成, 不在这里。
    prvSplashStart(SPLASH_SECONDS);
    log_debug("boot: countdown start");

    // --- 等倒计时结束(若加载已用掉部分时间, 则只补足剩余秒数) ---
    {
        uint8_t u8LastShown = 0xFFu;
        while (!prvSplashDone())
        {
            uint8_t u8Remain = prvSplashRemain();
            if (u8Remain != u8LastShown)              // 秒数变了才重画, 不无脑刷屏
            {
                u8LastShown = u8Remain;
                LCD_Fill(LCD_Width - 20, 0, LCD_Width - 1, 20, BLACK);   // 清掉上一个数字
                if (u8Remain > 0u)
                {
                    LCD_ShowNum(LCD_Width - 14, 2, (uint32_t)u8Remain, 1, 16);
                }
            }
            vTaskDelay(pdMS_TO_TICKS(20));
        }
        LCD_Fill(LCD_Width - 20, 0, LCD_Width - 1, 20, BLACK);       // clear countdown box before GUI
    }
```

## 9.3 四个要点

### 要点一：居中计算（带三元保护）

```c
uint16_t lx = (LCD_Width  > TITANS_LOGO_W) ? (uint16_t)((LCD_Width  - TITANS_LOGO_W) / 2) : 0u;
```

居中公式：(屏宽 - 图宽) / 2。三元保护防止"图比屏宽"时算出负数（虽然那种情况 `LCD_Show_Image` 会直接 return，但至少坐标不越界成乱值）。

### 要点二：图片一次调用搞定

`LCD_Show_Image` 内部 `LCD_Address_Set` + SPI/DMA 推送，无需逐像素（第 31 章 1.4、第 38 章）。

### 要点三：倒计时 = "局部擦写"范式（核心）

```c
uint8_t u8Remain = prvSplashRemain();    // 剩余秒数由软件定时器反推(xTimerGetExpiryTime), 计时权在定时器
if (u8Remain != u8LastShown)             // 秒数变了才动手, 不无脑刷屏
{
    u8LastShown = u8Remain;
    LCD_Fill(LCD_Width - 20, 0, LCD_Width - 1, 20, BLACK);      // ① 先刷背景
    if (u8Remain > 0u)
    {
        LCD_ShowNum(LCD_Width - 14, 2, (uint32_t)u8Remain, 1, 16);   // ② 再画新值
    }
}
vTaskDelay(pdMS_TO_TICKS(20));           // 20ms 渲染节奏, 不忙等 1s
```

这是第 32 章 2.4 讲的"无帧缓冲 = 局部擦写"范式的最小实例：

- **① 先刷背景**：把右上角 20×20 小方块刷黑，擦掉上一秒的数字；
- **② 再画新值**：画当前秒数。

若少了①，数字会一层层叠在旧数字上，变成一团黑块——因为屏不认得"上一帧是什么"，你不擦它就在那。

【提示】这个"先 Fill 再画"的小范式，是本项目所有动态内容（数值、焦点高亮、倒计时）的通用写法。记住它，后面设置页、刷新机制都在用它。

### 要点四：收尾再清一次

```c
LCD_Fill(LCD_Width - 20, 0, LCD_Width - 1, 20, BLACK);   // clear countdown box before GUI
```

循环结束（s=1 画完）后，最后一帧的 "1" 还停在屏上。切到 GUI 页面前不擦掉，它就会残留到主页背景上。所以这里再清一次，干净交接。

## 9.4 排错：图片不显示先查越界

第 38 章强调过：`LCD_Show_Image` 越界会**静默 return**。启动页若是黑屏、只有中文标题：

- 先确认 Logo 尺寸 ≤ 240×135（本工程 201×47，安全）；
- 若换了大图，用 `gen_image.py --resize` 缩到屏内；
- 居中后 `lx + 宽` 仍可能 > 240 吗？不会，因带三元保护且图本就小于屏。

---

## 9.5 本章小结

- 启动页是"裸机"界面：`gslc_Init` 后、建页面前，纯 `tftlcd` 直画，无 GUIslice 元素。
- 居中 = (屏宽-图宽)/2，带三元保护防负数。
- 倒计时用"先 Fill 刷背景、再 ShowNum 画新值"的局部擦写范式，是项目通用写法。
- 循环结束再清一次屏，避免末位数字残留到主页。
- 图片不显示先查越界（`LCD_Show_Image` 越界静默 return）。
