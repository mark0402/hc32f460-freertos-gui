# 第 45 章　手把手新增一个界面

【本章学习目标】

读完本章，你应该能独立地：

1. 从零新增一个 Page 2「系统信息页」，完整走通开发流程；
2. 正确扩页面池、加元素池、创建控件、注册中文、接入交互；
3. 把第 42 章的"刷新纪律"落实到新页面上（置脏、顺序、双缓冲）；
4. 形成一套"新增界面 checklist"，以后照着做不漏项。

前 12 章是"读懂"。本章是"动手"——把全书的机制综合起来，做一个完整的新页面。所有改动都在 `project/source/guislice/gui.c`（除跑一次脚本）。

## 13.1 需求与布局

**功能**：显示 4 行系统信息（电压 / 电流 / 温度 / 容量），底部一个「返回」按钮；长按移动焦点，短按在「返回」上时回到主页。

**入口（演示用，可自由替换）**：设置页长按焦点循环到末尾（第 9 个位置）即进入信息页，完全不改动现有 0~7 的交互。

**布局（240×135）**：

```
┌────────────────────────────────────────────┐
│ 系统信息                                    │  y 2..18
├────────────────────────────────────────────┤
│ 电压                              220.0 V  │  y 22..42
├────────────────────────────────────────────┤
│ 电流                               10.5 A  │  y 44..64
├────────────────────────────────────────────┤
│ 温度                               36.5 C  │  y 66..86
├────────────────────────────────────────────┤
│ 容量                                 80 %  │  y 88..108
├────────────────────────────────────────────┤
│                  返回                       │  y 112..132
└────────────────────────────────────────────┘
```

**元素清单**（**ID 必须全局唯一**，不能和现有 10、1~4、20、30~37 冲突）：

| ID | 类型 | 矩形 | 用途 |
|---|---|---|---|
| 40 | Txt | `{2, 2, 236, 16}` | 标题占位 |
| 41 | BtnTxt | `{2, 22, 236, 20}` | 电压行 |
| 42 | BtnTxt | `{2, 44, 236, 20}` | 电流行 |
| 43 | BtnTxt | `{2, 66, 236, 20}` | 温度行 |
| 44 | BtnTxt | `{2, 88, 236, 20}` | 容量行 |
| 45 | BtnTxt | `{2, 112, 236, 20}` | 返回 |

实际创建 6 个，元素池给 8（留余量）。

## 13.2 第一步：扩页面池

页面池是静态数组，页数要与实际一致。**改两处**：

```c
// 改前
static gslc_tsPage    sPage[2];
// 改后
static gslc_tsPage    sPage[3];
```

```c
// 改前
if (!gslc_Init(&gslc, &m_drv, sPage, 2, sFont, 1))
// 改后
if (!gslc_Init(&gslc, &m_drv, sPage, 3, sFont, 1))
```

`gslc_Init` 第 4 个参数是页数。忘了改会导致 `gslc_SetPageCur(&gslc, 2)` 越界。

## 13.3 第二步：加元素池

元素池同样是静态数组，创建元素时从池里分配。**池大小必须 ≥ 实际创建数**，超了 `ElemCreate*` 返回 NULL 且不报错。

在 `GUI_MAX_ELEM_SET` 定义附近追加：

```c
#define GUI_MAX_ELEM_INFO   8      // 实际创建 6 个, 留 2 个余量

static gslc_tsElem    sElemInfo[GUI_MAX_ELEM_INFO];
static gslc_tsElemRef sElemRefInfo[GUI_MAX_ELEM_INFO];

// 信息页元素指针
static gslc_tsElemRef* pElemInfoRow[4] = { NULL, NULL, NULL, NULL };
static gslc_tsElemRef* pElemBack       = NULL;

// 页面状态: 0=main, 1=settings, 2=info
static uint8_t g_u8InfoFocus = 0u;   // 0..3 信息行, 4 返回
```

数据源（用"×10 整数"表示一位小数，避免引入浮点格式化）：

```c
static uint16_t g_u16Voltage_x10 = 2200u;   // 220.0 V
static uint16_t g_u16Current_x10 = 105u;    // 10.5 A
static uint16_t g_u16Temp_x10    = 365u;    // 36.5 C
static uint8_t  g_u8Capacity     = 80u;     // 80 %
```

## 13.5 第四步：创建控件

在 `vGuiTask()` 中，设置页创建之后、`gslc_SetPageCur(&gslc, 0)` 之前追加：

```c
    // --- page 2: system info ---
    gslc_PageAdd(&gslc, 2, sElemInfo, GUI_MAX_ELEM_INFO, sElemRefInfo, GUI_MAX_ELEM_INFO);
    gslc_ElemCreateTxt(&gslc, 40, 2, (gslc_tsRect){2, 2, 236, 16},
                       "", 1u, 0);
    pElemInfoRow[0] = gslc_ElemCreateBtnTxt(&gslc, 41, 2, (gslc_tsRect){2,  22, 236, 20}, "", 1u, 0, NULL);
    pElemInfoRow[1] = gslc_ElemCreateBtnTxt(&gslc, 42, 2, (gslc_tsRect){2,  44, 236, 20}, "", 1u, 0, NULL);
    pElemInfoRow[2] = gslc_ElemCreateBtnTxt(&gslc, 43, 2, (gslc_tsRect){2,  66, 236, 20}, "", 1u, 0, NULL);
    pElemInfoRow[3] = gslc_ElemCreateBtnTxt(&gslc, 44, 2, (gslc_tsRect){2,  88, 236, 20}, "", 1u, 0, NULL);
    pElemBack       = gslc_ElemCreateBtnTxt(&gslc, 45, 2, (gslc_tsRect){2, 112, 236, 20}, "", 1u, 0, NULL);
    for (int i = 0; i < 4; i++) SetBtnColors(pElemInfoRow[i]);
    SetBtnColors(pElemBack);
```

要点：

- `gslc_PageAdd(&gslc, 2, ...)` 第 2 个参数是**页码**，必须和 `gslc_SetPageCur(&gslc, 2)` 对应。
- 元素 ID（40~45）与现有页面不冲突。
- **文本一律传 `""`**：中文稍后手绘。
- 复用 `SetBtnColors()` 保证配色一致。

## 13.6 第五步：绘制中文与数值

### 13.6.1 两个格式化助手

放在 `gui.c` 的 "time helpers" 附近。两个函数都**返回字符数**，便于右对齐，从而不需要 `strlen`（也不必引入 `<string.h>`）：

```c
// 把 "x10" 整数格式化为一位小数字符串, 例如 2200 -> "220.0"; 返回字符数
static uint8_t Format1Dec(char* b, uint16_t v_x10)
{
    uint8_t n = 0u;
    uint16_t i = v_x10 / 10u;
    char tmp[8]; uint8_t k = 0u;
    if (i == 0u) { tmp[k++] = '0'; }
    while (i > 0u) { tmp[k++] = (char)('0' + (i % 10u)); i /= 10u; }
    while (k > 0u) { b[n++] = tmp[--k]; }
    b[n++] = '.';
    b[n++] = (char)('0' + (v_x10 % 10u));
    b[n] = '\0';
    return n;
}

// 把无符号整数格式化为十进制字符串, 至少 1 位; 返回字符数
static uint8_t FormatUint(char* b, uint16_t v)
{
    uint8_t n = 0u;
    char tmp[8]; uint8_t k = 0u;
    if (v == 0u) { tmp[k++] = '0'; }
    while (v > 0u) { tmp[k++] = (char)('0' + (v % 10u)); v /= 10u; }
    while (k > 0u) { b[n++] = tmp[--k]; }
    b[n] = '\0';
    return n;
}
```

### 13.6.2 给 `DrawCnLabels()` 加页面分支

现有结构：二分支（`if (g_u8Page==0u) ... else ...`）。改成三分支，把原 `else` 内容搬进 `else if (g_u8Page==1u)`，再追加信息页：

```c
    if (g_u8Page == 0u)
    {
        ... 主页中文（不变）...
    }
    else if (g_u8Page == 1u)
    {
        ... 设置页中文（原 else 内容原样搬过来）...
    }
    else   // page 2: system info
    {
        DrawCnLabelInBox(2, 2, 236, 16, CNSTR_SYS_INFO, GREEN);

        const uint16_t IY[4]   = {22, 44, 66, 88};
        const uint8_t* ilbl[4] = { CNSTR_VOLTAGE, CNSTR_CURRENT, CNSTR_TEMP, CNSTR_CAPACITY };
        const char*    unit[4] = { "V", "A", "C", "%" };

        for (uint8_t i = 0u; i < 4u; i++)
        {
            uint16_t col = (g_u8InfoFocus == i) ? WHITE : GREEN;
            LCD_ShowChineseStr(6, (uint16_t)(IY[i] + 2), col, ilbl[i]);   // 左侧标签

            char     buf[16];
            uint8_t  n;
            switch (i) {
                case 0u: n = Format1Dec(buf, g_u16Voltage_x10); break;
                case 1u: n = Format1Dec(buf, g_u16Current_x10); break;
                case 2u: n = Format1Dec(buf, g_u16Temp_x10);    break;
                default: n = FormatUint(buf, g_u8Capacity);     break;
            }
            buf[n++] = ' ';
            for (const char* u = unit[i]; *u != '\0'; u++) { buf[n++] = *u; }
            buf[n] = '\0';

            // 右对齐: 236 格子宽 - 6 右边距 - 字符数*8
            uint16_t vw = (uint16_t)(n * 8u);
            POINT_COLOR = col;
            LCD_ShowString((uint16_t)(236u - 6u - vw), (uint16_t)(IY[i] + 2), 200, 16, 16, buf);
        }

        DrawCnLabelInBox(2, 112, 236, 20, CNSTR_BACK, (g_u8InfoFocus == 4u) ? WHITE : GREEN);
    }
```

要点：

- **焦点靠颜色区分**：当前焦点行 `WHITE`、其余 `GREEN`，与现有页面一致。
- **右对齐算法**：`236 - 6 - vw`，`vw = 字符数×8`（第 41 章 11.4 同款）。
- 单位（V/A/C/%）是 ASCII，拼进 `buf` 一起画，避免中英混排额外对齐。
- 这段手绘代码**必须处在 `gslc_Update()` 之后**（它本就在 `DrawCnLabels()` 内，而 `DrawCnLabels()` 在主循环的 Update 之后）——这是第 42 章纪律的落实。

## 13.7 第六步：接入按键与跳转

### 13.7.1 跳转与焦点函数

放在 `EnterSettings()` / `SaveSettings()` 附近：

```c
static void UpdateInfoFocus(void)
{
    for (int i = 0; i < 4; i++)
        gslc_ElemSetGlow(&gslc, pElemInfoRow[i], (i == (int)g_u8InfoFocus) ? true : false);
    gslc_ElemSetGlow(&gslc, pElemBack, (g_u8InfoFocus == 4u) ? true : false);
}

static void EnterInfo(void)
{
    g_u8InfoFocus = 0u;
    UpdateInfoFocus();
    g_u8Page = 2u;
    g_bCnDirty = true;               // 必须: 切页会清屏, 手绘内容要重画
    gslc_SetPageCur(&gslc, 2);
}

static void BackToMain(void)
{
    g_u8Page = 0u;
    g_bCnDirty    = true;            // 重画主页中文
    g_bShapeDirty = true;            // 重画主页图形
    gslc_SetPageCur(&gslc, 0);
}
```

【注意】`EnterInfo` / `BackToMain` 里的两个置脏都不能少——`gslc_SetPageCur` 整页清屏，手绘内容会被擦。漏 `g_bShapeDirty` 的表现是"从信息页返回主页后，右侧图形区一片黑"（第 42 章 12.5）。

### 13.7.2 改事件分支

原结构 `if (g_u8Page==0u){...} else {...}` 改成三分支：

```c
            if (g_u8Page == 0u)
            {
                // 主页
                if (ev == KEY_EVT_SHORT) {
                    g_u8Sel = (uint8_t)((g_u8Sel + 1u) % 4u);
                    UpdateSelGlow();
                    g_bCnDirty    = true;
                    g_bShapeDirty = true;
                } else if (ev == KEY_EVT_LONG) {
                    EnterSettings();
                }
            }
            else if (g_u8Page == 1u)
            {
                // 设置页: 长按焦点循环, 到末尾进信息页
                if (ev == KEY_EVT_LONG) {
                    g_u8SetFocus = (uint8_t)((g_u8SetFocus + 1u) % 9u);  // 0..7 原有, 8 = 进入信息页
                    if (g_u8SetFocus == 8u) {
                        EnterInfo();
                        g_u8SetFocus = 0u;    // 复位
                    } else {
                        UpdateSetFocus();
                        g_bCnDirty = true;
                    }
                } else if (ev == KEY_EVT_SHORT) {
                    ActOnFocus();
                }
            }
            else   // info page
            {
                if (ev == KEY_EVT_LONG) {
                    g_u8InfoFocus = (uint8_t)((g_u8InfoFocus + 1u) % 5u);   // 4 行 + 返回
                    UpdateInfoFocus();
                    g_bCnDirty = true;
                } else if (ev == KEY_EVT_SHORT) {
                    if (g_u8InfoFocus == 4u) BackToMain();
                }
            }
```

`UpdateSetFocus()` 判断 0..7，焦点 8 不匹配任何元素，进入信息页后由 `UpdateInfoFocus()` 接管，无残留高亮。

## 13.10 常见变体

**想加更多行？** 调大 `GUI_MAX_ELEM_INFO`；扩大 `pElemInfoRow[]` / `IY[]` / `ilbl[]` / `unit[]`；焦点取模 `% N`（N=行数+1）；重算 y 坐标不超 135。

**想让某行可编辑？** 照搬设置页：加"编辑副本"变量 → 短按该焦点 `IncXxx()` 改副本 → 置 `g_bCnDirty` → 提供保存/取消提交或丢弃。

**想用按钮入口而非"长按到末尾"？** 在设置页加一个按钮（如焦点 8 对应它），`gslc_ElemCreateBtnTxt(&gslc, 46, 1, (gslc_tsRect){2,96,76,30}, "", 1u, 0, NULL)`，把保存/取消矩形缩以腾空间，`GUI_MAX_ELEM_SET` 调大，焦点 8 短按 `EnterInfo()`。

## 13.11 本章小结

新增页面固定套路：

```
扩页面池 → 加元素池 → 建页 PageAdd → 创建控件(ID 唯一/文本空串)
   → 绘制回调加分支 → 跳转函数(必置脏) → 事件循环加分支 → 词条跑脚本 → 编译
```

三个最易翻车点：

1. `gslc_Init` 的页数忘了改 → 页面越界；
2. 切页时忘了置脏 → 手绘内容被清屏擦掉；
3. 元素 ID 冲突或元素池不够 → 控件不显示且不报错。
