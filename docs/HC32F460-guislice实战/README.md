# 《HC32F460 + GUIslice 嵌入式界面开发实战》

> 一部面向**没用过 GUIslice、甚至没做过嵌入式界面**的读者的实战教程。
> 全部内容取自本仓库 `hc32f460-lcd` 工程，代码、路径、坐标均可直接对照源码。

---

## 一、这本书写给谁

- 你了解 C 语言、会用 Keil；
- 你接触过 STM32/HC32 这类 MCU，会点灯、会串口；
- 但你对 GUIslice 一无所知，甚至对"做一个带界面的嵌入式程序"该从哪里下手也模糊。

如果是这样，这本书就是为你写的。它不假设你懂任何 GUI 框架，而是从"屏幕上的一个像素是怎么出现的"讲起，一步步带你理解：

1. 嵌入式 GUI 到底在干什么；
2. GUIslice 这套框架用什么零件拼界面；
3. 怎么把它搬到 HC32F460 上；
4. 图片和中文这种"麻烦资源"怎么喂给固件；
5. 现有三个页面是怎么画出来的；
6. 最后，自己动手加一个新页面。

## 三、本书约定

### 1. 每章的体例

为方便自学，每一章都按固定结构组织：

```
【本章学习目标】      读完你应该能回答哪几个问题
  正文讲解           概念 + 原理 + 代码
  【提示】           可跳过但不该忽略的经验
  【注意】           一踩就坑的地方
  【动手试】         可以立刻在板上验证的小练习
【本章小结】         一页纸回顾要点
【思考与练习】        自测题（答案可回正文找）
```

### 2. 代码引用格式

凡是引用工程里现成的代码，都用 `起始行:结束行:文件路径` 标注，方便你跳去读原文：

```34:46:project/source/guislice/gslc_drv_hc32.c
bool gslc_DrvInit(gslc_tsGui* pGui)
{
    ...
}
```

### 3. 几条贯穿全书的"铁律"

读到后面会反复用到，先记住这三条：

- **铁律一（GUIslice 只管一部分）**：本工程 GUIslice 只负责画按钮框和状态栏文字；图形和中国字是绕过它、直接调 `tftlcd` 手画的。手绘**必须在 `gslc_Update()` 之后**。
- **铁律二（无帧缓冲 = 局部擦写）**：屏幕没有显存，任何动态内容都要"先刷背景再重画"。
- **铁律三（C 里没有中文）**：中文一律由 Python 脚本生成十六进制字节数组（C 源码不含中文）；本工程编译器为 AC6/armclang，能否编译中文与显示机制无关，显示走点阵手绘。

## 五、环境要求

| 项 | 版本 |
|---|---|
| IDE / 编译器 | Keil MDK，ARM Compiler 6（AC6 / armclang） |
| Python（仅取资源时需要） | 3.x + `pillow` |
| 中文字体（取模用） | 系统自带 `simhei.ttf` 等，脚本自动查找 |

取资源的两个脚本在 `project/tools/`：

```bash
cd project/tools
python gen_image.py          --help    # 图片 → RGB565 头文件
python gen_chinese_font.py             # 中文 → 点阵字库 + 词条
```
