设置页把"焦点管理 + 中文 + 数字 + 编辑副本"四种机制集中在一起，是理解交互逻辑的最佳样本。

## 11.1 布局

```
┌────────────────────────────────────────────┐
│ 时间设置                                    │  y 2..18
├──────────┬──────────┬──────────┐           │
│ 年  2026 │ 月    01 │ 日    01 │           │  y 20..44
├──────────┼──────────┼──────────┤           │
│ 时    00 │ 分    00 │ 秒    00 │           │  y 46..70
└──────────┴──────────┴──────────┘           │
│      保存      │      取消      │           │  y 96..126
└────────────────────────────────────────────┘
 x = 2 / 82 / 162，每个宽度 76
```

3 列 × 2 行共 6 个时间字段，底部两个按钮。焦点在 0~5 之间移动，6=保存、7=取消。

---

## 11.2 编辑副本模式

```123:124:project/source/guislice/gui.c
static app_time_t g_tm_edit = { 2026u, 1u, 1u, 0u, 0u, 0u };  // 设置页工作副本(墙上时钟已独立到 app_time.c)
static uint32_t   s_u32ClockVer = 0u;   // 已绘制的时钟版本号(用于"变了才重绘")
```

- **进入设置页**：`AppTime_Get(&g_tm_edit)`（从时间服务载入当前值作为副本）；
- **保存**：`AppTime_Set(...)`（提交副本给时间服务，由它校验 + 持久化）；
- **取消**：`AppTime_Get(&g_tm_edit)`（重新取回当前值，丢弃修改）。

【提示】**编辑副本模式**是嵌入式设置页的通用范式：用户改的是"副本"，只有确认才提交。好处是"取消"零成本——不需要记录"改了哪些、怎么回滚"，直接丢弃副本即可。缺点是要两份内存，但 `sys_time_t` 才十几个字节，无所谓。

## 11.3 焦点用 glow

焦点高亮靠 `gslc_ElemSetGlow`——这是 GUIslice 原生的"聚焦发光"机制：

```324:330:project/source/guislice/gui.c
static void UpdateSetFocus(void)
{
    for (int i = 0; i < 6; i++)
        gslc_ElemSetGlow(&gslc, pElemSet[i], (i == (int)g_u8SetFocus) ? true : false);
    gslc_ElemSetGlow(&gslc, pElemSave,   (g_u8SetFocus == 6u) ? true : false);
    gslc_ElemSetGlow(&gslc, pElemCancel, (g_u8SetFocus == 7u) ? true : false);
}
```

配色在 `SetBtnColors` 里预置：常态蓝框黑底，glow（聚焦）态黄框蓝底白字。

```332:338:project/source/guislice/gui.c
static void SetBtnColors(gslc_tsElemRef* p)
{
    if (!p) return;
    // normal: blue frame + black fill + white text; focused(glow): yellow frame + blue fill + white text
    gslc_ElemSetCol(&gslc, p, GSLC_COL_BLUE, GSLC_COL_BLACK, GSLC_COL_BLUE);
    gslc_ElemSetGlowCol(&gslc, p, GSLC_COL_YELLOW, GSLC_COL_BLUE, GSLC_COL_WHITE);
}
```

【注意】glow 是 GUIslice 元素自己的高亮（按钮框变色）。但**按钮上的中文是手绘的，GUIslice 管不到**——所以中文的高亮要靠我们自己在绘制时按 `g_u8SetFocus` 选色（见 11.4）。

## 11.4 中文标签与数字混排

每行：左边中文标签、右边数值。数值用 `LCD_ShowNum` 画，并按位数右对齐。

```266:283:project/source/guislice/gui.c
        for (uint8_t i = 0u; i < 6u; i++)
        {
            uint16_t col = (g_u8SetFocus == i) ? WHITE : GREEN;
            LCD_ShowChineseStr((uint16_t)(FX[i] + 4u), (uint16_t)(FY[i] + 4u), col, lbl[i]);   // label left
            uint32_t val; uint8_t len;
            switch (i) {
                case 0u: val = g_tm_edit.year;   len = 4u; break;
                case 1u: val = g_tm_edit.month;  len = 2u; break;
                ...
            }
            uint16_t vw = (uint16_t)(len * 8u);
            uint16_t vx = (uint16_t)(FX[i] + 76u - 6u - vw);
            uint16_t vy = (uint16_t)(FY[i] + 4u);
            POINT_COLOR = col;
            LCD_ShowNum(vx, vy, val, len, 16u);
        }
```

**右对齐算法**：`FX[i] + 76 - 6 - vw`
- `76`：格子宽；
- `6`：右边距；
- `vw = len × 8`：数值像素宽（每位 8px）。

三者算出数值起点，实现右对齐——无论"2026"还是"01"，右边缘都贴着同一根竖线。

【提示】这里"中文标签 + 数字"完全是手绘（绕开 GUIslice）。好处是布局自由；代价是选中高亮要自己按焦点选色，且每帧要重画（脏标记）。

## 11.5 短按语义

```384:394:project/source/guislice/gui.c
static void ActOnFocus(void)
{
    if (g_u8SetFocus < 6u) {
        IncField(g_u8SetFocus);
        g_bCnDirty = true;   // value changed -> repaint field label + value
    } else if (g_u8SetFocus == 6u) {
        SaveSettings();
    } else {
        CancelSettings();
    }
}
```

- **焦点在字段（0~5）**：`IncField` 给当前字段 +1（带范围环绕）；
- **焦点在保存（6）**：`SaveSettings()` 提交副本；
- **焦点在取消（7）**：`CancelSettings()` 丢弃副本。

每个修改后都置 `g_bCnDirty`——因为值变了，手绘的中文/数字要重画。

### IncField 范围环绕

`IncField` 对每个字段做范围环绕：年 2026..2099、月 1..12、日按当月天数（含闰年）、时 0..23、分秒 0..59。跨月天数由 `DaysInMonth()` 提供。

```c
// 示意
case 1: // month
    g_tm_edit.month = (g_tm_edit.month % 12) + 1; break;
case 2: // day
    uint8_t dim = DaysInMonth(g_tm_edit.year, g_tm_edit.month);
    g_tm_edit.day = (g_tm_edit.day % dim) + 1; break;
```

【注意】"日"的上限依赖"月"，闰年 2 月是 29 天。若只用 `% 31` 会出错。所以 `DaysInMonth` 必须处理闰年——这是这类"日期编辑器"最容易出 bug 的细节。

## 11.6 本章小结

- 设置页：6 字段 3×2 + 保存/取消，焦点 0~7 循环。
- 编辑副本模式：改的是 `g_tm_edit`，保存提交、取消丢弃，零回滚成本。
- 焦点高亮 = GUIslice 的 glow（按钮框）+ 自绘中文按焦点选色。
- 数字右对齐：起点 = 格子宽 - 右边距 - 位宽×8。
- 短按：字段+1 / 保存 / 取消；修改后必置 `g_bCnDirty`。
