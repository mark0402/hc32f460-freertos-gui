# 第 42 章　主页详解：图形 + 按钮 + 中文 + 状态栏

【本章学习目标】

读完本章，你应该能回答：

1. 主页的布局是怎样的？四类内容（图形/按钮/中文/状态栏）各由谁绘制？
2. 为什么按钮文本传空串 `""`，中文却显示出来了？
3. 右侧图形区是怎么画的？第一件事为什么永远是"清底"？
4. 五角星为什么用"顶点表"而不手写十条线？
5. 主页的短按/长按要求是什么？状态变化后做了什么？

主页是第一个真正的 GUIslice 页面，也是"混合绘制"最集中的地方。读懂它，后续页面都是同构的。

## 10.1 布局

```
┌────────────┬──────────────────────────────────┐
│ 矩形       │                                  │
├────────────┤        图形显示区                 │
│ 三角形     │     RA_X0=78  RA_Y0=2             │  y 2..108
├────────────┤     RA_X1=238 RA_Y1=108           │
│ 五角星     │     (手绘, 非 GUIslice 元素)       │
├────────────┤                                  │
│ 六芒星     │                                  │
├────────────┴──────────────────────────────────┤
│ 2026-01-01 00:00:00   (GUIslice 文本元素)      │  y 112..134
└───────────────────────────────────────────────┘
 x 2..74 为 4 个按钮，y = 2 / 30 / 58 / 86，h=24
```

左侧 4 个按钮（矩形/三角形/五角星/六芒星），选中哪个，右侧就显示哪个图形；底部状态栏是实时时钟（GUIslice 文本元素）。

---

## 10.2 四类内容的绘制归属

| 内容 | 谁画 | 怎么做 |
|---|---|---|
| 4 个按钮框 + 高亮 | **GUIslice** | `ElemCreateBtnTxt`，文本传空串 `""` |
| 右侧图形 | **手绘** | `LCD_Fill` 清底 + `LCD_DrawLine` 画线 |
| 按钮上的中文 | **手绘** | `DrawCnLabelInBox()` 居中画 |
| 底部状态栏时间 | **GUIslice** | `ElemCreateTxt` + `ElemSetTxtStr` |

这正是第 33 章铁律一的落地：**GUIslice 只管按钮框和状态栏，图形和中文都是手绘**。

## 10.3 元素创建

```450:458:project/source/guislice/gui.c
    // --- page 0: main ---
    gslc_PageAdd(&gslc, 0, sElemMain, GUI_MAX_ELEM_MAIN, sElemRefMain, GUI_MAX_ELEM_MAIN);
    pElemStatus = gslc_ElemCreateTxt(&gslc, 10, 0, (gslc_tsRect){0, 112, 240, 22},
                                     sStatus, sizeof(sStatus), 0);
    pElemBtn[0] = gslc_ElemCreateBtnTxt(&gslc, 1, 0, (gslc_tsRect){2,  2, 72, 24}, "", 1u, 0, NULL);
    pElemBtn[1] = gslc_ElemCreateBtnTxt(&gslc, 2, 0, (gslc_tsRect){2, 30, 72, 24}, "", 1u, 0, NULL);
    pElemBtn[2] = gslc_ElemCreateBtnTxt(&gslc, 3, 0, (gslc_tsRect){2, 58, 72, 24}, "", 1u, 0, NULL);
    pElemBtn[3] = gslc_ElemCreateBtnTxt(&gslc, 4, 0, (gslc_tsRect){2, 86, 72, 24}, "", 1u, 0, NULL);
    for (int i = 0; i < 4; i++) SetBtnColors(pElemBtn[i]);
```

要点：

- **按钮文本传 `""`**：GUIslice 画不了中文，按钮只当"画框 + 高亮"用，中文稍后手绘（第 34 章 4.3 的"空按钮 + 手绘中文"技巧）。
- **ID 唯一**：主页用 10（状态栏）和 1~4；设置页用 20、30~37。跨页面也不能撞。
- **元素池留余量**：`GUI_MAX_ELEM_MAIN` 为 8，实际创建 5 个。池不够 `ElemCreate` 返回 NULL 且不报错。
- **统一配色**：`SetBtnColors` 给每个按钮设"蓝框黑底"常态、"黄框蓝底白字"高亮态。

## 10.4 图形区：清底 + 画线 + 顶点表

图形区坐标常量：

```134:137:project/source/guislice/gui.c
// right shape display area (screen coords)
#define RA_X0   78
#define RA_Y0   2
#define RA_X1   238
#define RA_Y1   108
```

绘制入口：

```166:181:project/source/guislice/gui.c
static void DrawShapeArea(uint8_t sel)
{
    LCD_Fill(RA_X0, RA_Y0, RA_X1, RA_Y1, BLACK);   // ① 先清底

    uint16_t col = GREEN;   // 0x07E0
    int16_t  cx  = (int16_t)((RA_X0 + RA_X1) / 2);
    int16_t  cy  = (int16_t)((RA_Y0 + RA_Y1) / 2);

    switch (sel)
    {
    case 0: // rectangle RECT
        lcd_line((uint16_t)(cx - 45), (uint16_t)(cy - 32), (uint16_t)(cx + 45), (uint16_t)(cy - 32), col);
        ...
```

**① 先清底** `LCD_Fill(..., BLACK)` 是图形区的"局部擦写"——切换图形时，不擦旧线条会残留。`DrawShapeArea` 每次调用都从清底开始，保证只显示当前选中的图形。

`lcd_line()` 是薄封装——设画笔色再画线：

```153:157:project/source/guislice/gui.c
static void lcd_line(uint16_t x0, uint16_t y0, uint16_t x1, uint16_t y1, uint16_t col)
{
    POINT_COLOR = col;
    LCD_DrawLine(x0, y0, x1, y1);
}
```

### 五角星用顶点表

与其手写十条 `lcd_line`，不如用"顶点表"驱动，清晰且易改：

```160:164:project/source/guislice/gui.c
// 5-point star (10 vertices, alternating outer/inner): offsets from center
static const int8_t s_Star5[10][2] =
{
    {  0, -42}, { 10, -14}, { 40, -13}, { 16,   5}, { 25,  34},
    {  0,  17}, {-25,  34}, {-16,   5}, {-40, -13}, {-10, -14}
};
```

```c
    for (int k = 0; k < 10; k++)
    {
        int n = (k + 1) % 10;
        lcd_line(cx + s_Star5[k][0], cy + s_Star5[k][1],
                 cx + s_Star5[n][0], cy + s_Star5[n][1], col);
    }
```

【提示】"用数据表驱动绘制"是嵌入式画复杂图形的通用技巧。把图形变成"顶点数组 + 连线循环"，比硬编码一堆坐标易读、易改。三角形是 3 顶点、矩形 4 顶点、六芒星 12 顶点，同理。

## 10.5 按钮上的中文：居中叠加

中文不归 GUIslice 管，用 `DrawCnLabelInBox` 在按钮矩形内居中画：

```254:257:project/source/guislice/gui.c
        DrawCnLabelInBox(2,  2, 72, 24, CNSTR_RECT,     (g_u8Sel==0u)?WHITE:GREEN);
        DrawCnLabelInBox(2, 30, 72, 24, CNSTR_TRI,      (g_u8Sel==1u)?WHITE:GREEN);
        DrawCnLabelInBox(2, 58, 72, 24, CNSTR_PENTA,    (g_u8Sel==2u)?WHITE:GREEN);
        DrawCnLabelInBox(2, 86, 72, 24, CNSTR_HEXAGRAM, (g_u8Sel==3u)?WHITE:GREEN);
```

选中项用 `WHITE`、其余 `GREEN`——**颜色即高亮**。注意这些调用发生在 `gslc_Update()` **之后**（`DrawCnLabels` 里），否则会被按钮重绘擦掉（第 33 章铁律一、第 42 章详述）。

`DrawCnLabelInBox` 的居中算法（按字符数算宽度，非字节数）：

```240:248:project/source/guislice/gui.c
static void DrawCnLabelInBox(uint16_t x, uint16_t y, uint16_t w, uint16_t h,
                             const uint8_t* str, uint16_t color)
{
    uint16_t n  = CnStrChars(str);
    uint16_t tw = (uint16_t)(n * 16u);
    uint16_t px = (uint16_t)(x + ((w > tw) ? ((w - tw) / 2u) : 0u));
    uint16_t py = (uint16_t)(y + ((h > 16u) ? ((h - 16u) / 2u) : 0u));
    LCD_ShowChineseStr(px, py, color, str);
}
```

## 10.6 交互：短按切图形，长按进设置

```500:507:project/source/guislice/gui.c
                if (ev == KEY_EVT_SHORT) {
                    g_u8Sel = (uint8_t)((g_u8Sel + 1u) % 4u);
                    UpdateSelGlow();
                    g_bCnDirty = true;   // selection changed -> repaint highlight
                    g_bShapeDirty = true;
                } else if (ev == KEY_EVT_LONG) {
                    EnterSettings();
                }
```

- **短按**：`g_u8Sel` 在 0~3 循环，更新按钮高亮（`UpdateSelGlow`），并**置两个脏标记**（图形要重画、中文高亮色要重画）。
- **长按**：`EnterSettings()` 切到设置页（内部会置脏 + `SetPageCur`，见第 11、12 章）。

【注意】这里再次看到"状态一变就置脏"的纪律。漏掉 `g_bShapeDirty`，切换图形后右侧会残留旧图形；漏掉 `g_bCnDirty`，按钮高亮色不更新。脏标记是 GUI 正确性的命脉。

## 10.7 本章小结

- 主页四类内容：按钮框/状态栏由 GUIslice 画，图形/中文手绘（混合绘制）。
- 按钮文本传空串 `""`，中文靠 `DrawCnLabelInBox` 叠加；颜色区分选中态。
- 图形区 `DrawShapeArea` 第一件事是 `LCD_Fill` 清底，避免旧图形残留；五角星用顶点表驱动。
- 交互：短按切图形（置双脏标记）、长按进设置页。
- 所有"状态变化 → 置脏"的纪律，是保证刷新正确的关键。
