# 《HC32F460 零基础实战》导读

一本面向零基础读者的 HC32F460 实战书。本书按"由浅入深、项目驱动"组织成 **三篇**,从裸机外设(DDL)一路走到带图形界面的实时系统:

| 篇 | 主题 | 文档目录 | 章节 |
|----|------|----------|------|
| 第一篇 | DDL 外设驱动库(裸机) | `HC32F460零基础实战DDL/` | 第 1–15 章 |
| 第二篇 | FreeRTOS 实时操作系统 | `HC32F460-freeRTOS实战/` | 第 16–30 章(原理 16–19 / 应用 20–30) |
| 第三篇 | GUIslice 图形界面 | `HC32F460-guislice实战/` | 第 31–45 章 + 附录 |

## 教学系列书籍

本仓库配套的教学系列由以下三篇组成，按「裸机 → FreeRTOS → GUI」循序学习：

1. [第一篇：HC32F460 零基础实战 DDL](HC32F460零基础实战DDL/) —— 从 GPIO、USART、定时器、SPI、ADC 和中断等裸机外设入门。
2. [第二篇：HC32F460 FreeRTOS 实战](HC32F460-freeRTOS实战/) —— 从任务、调度、通信和中断基础，逐步构建多任务图形化终端。
3. [第三篇：HC32F460 GUIslice 实战](HC32F460-guislice实战/) —— 完成 GUIslice 移植、彩屏界面、中文字库和图片资源等 GUI 开发。

## 为什么是三篇
- **第一篇** 打基础:用华大半导体的 DDL 库把芯片每个外设(GPIO/USART/定时器/ADC/SPI…)跑起来,建立"裸机前后台"的心智模型。
- **第二篇** 是 **第一篇的续本**:不再重复外设细节,而是把 FreeRTOS 一点点"长"进点灯例程,最终得到当前这个支持串口配置的图形化万年历工程。它分上下两部——原理篇(16–19 章)讲透任务/调度/通信/中断;应用篇(20–30 章)回到真实工程逐功能开发,含软件定时器走时、串口命令行、加屏 GUI/KEY 任务、工程全景、常用机制速览。它承接第一篇的"裸机点灯",是本书的重点。
- **第三篇** 专攻图形界面:在已经会 RTOS 的基础上,用 GUIslice 把万年历的界面、中文字库、图片资源做出来。内容可直接复用,无需改动。

> 各分册章节范围:DDL 1–15、FreeRTOS 16–30、GUIslice 31–45 + 附录。注意 FreeRTOS 应用篇(26–30 章:软件定时器 / 串口命令行 / 加屏 / 工程全景 / 机制速览)与 GUIslice 分册(31–45 章)在文件章节号上不再重叠(FreeRTOS 止于 30,GUIslice 从 31 起)。前者讲 RTOS 机制与"把屏接进 RTOS",后者讲界面实现细节。阅读顺序上,FreeRTOS 应用篇的 28(加屏)、29(工程全景)是通往 GUIslice 篇的桥梁,读完 FreeRTOS 应用篇即可接 GUIslice 分册的第 31 章(需求与软硬件全景)。物理上仍按三个文件夹分册,方便按需取用。

## 工程与例程位置
- **起点例程(裸机点灯)**:`HC32F460 Demo\example\HC32F460JEUA\1.gpio\gpio_output\`
- **最终工程(图形化万年历)**:`project/`(MDK 工程 `project\MDK\*.uvprojx`,AC6/armclang 构建)
- FreeRTOS 内核源码位于 `project\FreeRTOS\`,GUIslice 位于 `GUIslice-master\` 与 `project\source\guislice\`。

## 工具链
- Keil MDK(ARM Compiler 6 / armclang,本工程采用)+ ARM Cortex-M4 FPU 端口 `RVDS/ARM_CM4F`
- 或 GCC(`arm-none-eabi-gcc`)+ 端口 `GCC/ARM_CM4F`
- HC32F460 DDL 库(`hc32_ddl.h`)

## 参考官方文档
- FreeRTOS 官方手册与 API 参考:https://www.freertos.org/
- 华大半导体 HC32F460 数据手册 / 用户手册 / DDL 库说明(见第一篇)
- 本书第二篇在讲解概念时尽量对照官方文档的视角,工程代码则以当前仓库为准(原生 FreeRTOS V10.4.6)。

## 推荐阅读顺序
1. 先读第一篇第 1–15 章,把裸机点灯和各个外设跑通。
2. 接着读第二篇第 16–30 章(原理 16–19 + 应用 20–30),跟着"点灯 → 移植 RTOS → 多任务 → 软件定时器走时 → 串口命令行 → 加屏 → 工程全景"的主线动手。
3. 最后按需查阅第三篇 GUIslice(分册第 31–45 章),深入界面实现。
