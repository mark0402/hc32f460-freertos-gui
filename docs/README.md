# HC32F460 零基础实战教程导读

这是一套面向零基础开发者的 HC32F460 实战教程，按"由浅入深、项目驱动"组织为 **三篇**，内容从裸机外设（DDL）逐步延伸至带图形界面的实时系统：

| 篇 | 主题 | 文档目录 | 章节 |
|----|------|----------|------|
| 第一篇 | DDL 外设驱动库(裸机) | `HC32F460零基础实战DDL/` | 第 1–15 章 |
| 第二篇 | FreeRTOS 实时操作系统 | `HC32F460-freeRTOS实战/` | 第 16–30 章(原理 16–19 / 应用 20–30) |
| 第三篇 | GUIslice 图形界面 | `HC32F460-guislice实战/` | 第 31–45 章 + 附录 |

## 为什么分为三篇
- **第一篇** 打基础：使用华大半导体的 DDL 库完成 GPIO、USART、定时器、ADC、SPI 等外设开发，建立"裸机前后台"的基本认识。
- **第二篇** 延续第一篇的工程，重点介绍 FreeRTOS 在 HC32F460 上的移植与应用，最终实现支持串口配置的图形化万年历工程。内容分为两部分：原理篇（16–19 章）介绍任务、调度、通信与中断；应用篇（20–30 章）结合实际工程完成软件定时器走时、串口命令行、GUI/KEY 任务、工程全景与常用机制速览，是本教程的核心部分。
- **第三篇** 专注图形界面：在 FreeRTOS 工程基础上，使用 GUIslice 完成万年历界面、中文字库与图片资源开发，相关方法可复用于其他嵌入式 GUI 项目。

> 各教程篇的章节范围：DDL 1–15、FreeRTOS 16–30、GUIslice 31–45 + 附录。注意 FreeRTOS 应用篇（26–30 章：软件定时器 / 串口命令行 / 加屏 / 工程全景 / 机制速览）与 GUIslice 篇（31–45 章）在文件章节号上不再重叠（FreeRTOS 止于 30，GUIslice 从 31 起）。前者讲 RTOS 机制与"把屏接进 RTOS"，后者讲界面实现细节。阅读顺序上，FreeRTOS 应用篇的第 28 章（加屏）、第 29 章（工程全景）是通往 GUIslice 篇的桥梁，读完 FreeRTOS 应用篇即可接续 GUIslice 篇第 31 章（需求与软硬件全景）。文件仍按三个目录组织，方便按需取用。

## 工程与例程位置
- **起点例程(裸机点灯)**:`HC32F460 Demo\example\HC32F460JEUA\1.gpio\gpio_output\`
- **最终工程(图形化万年历)**:`project/`(MDK 工程 `project\MDK\*.uvprojx`,AC6/armclang 构建)
- FreeRTOS 内核源码位于 `project\FreeRTOS\`,GUIslice 位于 `GUIslice-master\` 与 `project\source\guislice\`。

## 工具链
- Keil MDK(ARM Compiler 6 / armclang,本工程采用)+ ARM Cortex-M4 FPU 端口 `RVDS/ARM_CM4F`
- 或 GCC(`arm-none-eabi-gcc`)+ 端口 `GCC/ARM_CM4F`
- HC32F460 DDL 库(`hc32_ddl.h`)

## 参考官方文档
- FreeRTOS 官方手册与 API 参考:https://www.freertos.org/
- 华大半导体 HC32F460 数据手册 / 用户手册 / DDL 库说明(见第一篇)
- 本教程第二篇在讲解概念时尽量对照官方文档的视角，工程代码则以当前仓库为准（原生 FreeRTOS V10.4.6）。

## 推荐阅读顺序
1. 先读第一篇第 1–15 章,把裸机点灯和各个外设跑通。
2. 接着读第二篇第 16–30 章(原理 16–19 + 应用 20–30),跟着"点灯 → 移植 RTOS → 多任务 → 软件定时器走时 → 串口命令行 → 加屏 → 工程全景"的主线动手。
3. 最后按需查阅第三篇 GUIslice（第 31–45 章），深入界面实现。
